# Kaustab's Portfolio Website 🌟

This repository contains the source code for **Kaustab's personal portfolio website**, showcasing projects, skills, and achievements in a visually appealing and interactive format.

## Features ✨

- **Responsive Design**: Optimized for desktops, tablets, and mobile devices.
- **Project Highlights**: Dedicated sections for detailed project showcases, including images and descriptions.
- **Achievements**: A collection of awards and recognitions with visual representation.
- **Modern Aesthetics**: Light and dark-themed backgrounds for enhanced user experience.
- **Firebase Hosting**: Deployed and managed via Firebase for seamless performance.

## Live Website 🌐

Explore the portfolio live at: [kaustabsamanta.web.app](https://kaustabsamanta.web.app)

## Directory Structure 📁

- **`assets/`**: Contains all static resources.
  - **`css/`**: Stylesheets for the website.
  - **`icons/`**: Icon assets for UI elements.
  - **`images/`**: High-quality images for projects, awards, and more.
- **`portfolioDetails/`**: HTML files for individual project detail pages.
- **`js/`**: JavaScript logic for interactivity.
- **`index.html`**: Main entry point for the website.
- **`firebase.json`** & **`.firebaserc`**: Firebase configuration files for deployment.

## Key Projects 🛠️

- **Shortify.NET**: A URL shortener application with a sleek UI and robust backend.
- **ShopEase**: A user-friendly e-commerce platform.
- **Portfolio Redesigns**: Multiple iterations of the portfolio to improve user experience.

## How to Run Locally 🖥️

1. Clone the repository:
   ```bash
   git clone https://github.com/scriptsage001-kaustab-portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd scriptsage001-kaustab-portfolio
   ```
3. Open `index.html` in your browser to explore the portfolio.
